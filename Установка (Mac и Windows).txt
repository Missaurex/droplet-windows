DROPLET — УСТАНОВКА
Mac: Droplet (чёлка, голосовой Клод, питомец, звонки → amoCRM).
Windows: Droplet Звонки (только звонки → amoCRM).


==================== MAC ====================
Нужен Mac на Apple Silicon (M1 и новее), macOS 14 или новее, Google Chrome и подписка Claude Pro.

1. Скачай Droplet.zip: https://github.com/Missaurex/droplet/releases/latest
   Открой архив и перетащи Droplet.app в «Программы». Запусти.
   Если macOS не даёт открыть: Системные настройки → Конфиденциальность и безопасность →
   внизу «Всё равно открыть» напротив Droplet.
   Если пишет «Не удаётся открыть программу»: открой Терминал, вставь строку и нажми Enter, потом открой снова:
   xattr -cr /Applications/Droplet.app

2. Кликни по капле в строке меню → окно Droplet → «Клод» → «Включить всё».
   Droplet сам поставит Claude Code и откроет вход (подписка Pro). Дальше соглашайся в окнах macOS.

3. amoCRM: окно Droplet → «Созвоны» → карточка amoCRM. Жми кнопку, пока карточка не станет зелёной:
   • «Открыть amoCRM» — открой amoCRM в Chrome и войди;
   • «Включить» — в Chrome откроется меню, кликни подсвеченный пункт
     «Разрешить JavaScript из Apple Events». Если macOS спросит про Chrome — «ОК».

4. Звони: Sipuni — с открытой сделкой; WhatsApp — Droplet сам найдёт и откроет сделку по номеру.
   После звонка в «Примечание» сделки: сначала КЛЮЧЕВОЕ, потом ВЕСЬ ДИАЛОГ.
   Не уверен, чья карточка — в amoCRM не пишет, итог в буфере (вставь ⌘V).
   Обновления приходят сами.


==================== WINDOWS ====================
Нужен Windows 10 или 11, Google Chrome и подписка Claude Pro.

1. Скачай DropletCalls-Windows.zip: https://github.com/Missaurex/droplet-windows/releases/latest
   Нажми на архив правой кнопкой → «Извлечь всё» → выбери «Документы». Открой папку DropletCalls
   и запусти DropletCalls.exe.
   Если Windows покажет синее окно «Система Windows защитила ваш компьютер» — нажми «Подробнее» →
   «Выполнить в любом случае» (программа не из Microsoft Store, это нормально).

2. Откроется окно «Подключение». Нажимай кнопки сверху вниз, пока везде не будут галочки ✓:
   • Claude Code → «Установить» (ставится сам, около минуты);
   • Вход в Claude → «Войти»: откроется браузер, войди своей подпиской Pro и нажми «Разрешить»;
   • Расширение Chrome → «Установить»: откроется Chrome и папка с расширением.
     В Chrome справа сверху включи «Режим разработчика», нажми «Загрузить распакованное»
     и выбери открывшуюся папку extension;
   • amoCRM → «Открыть»: открой свою amoCRM в Chrome и войди, как обычно;
   • Распознавание речи → «Скачать» (один раз, около 500 МБ).
   Окно можно открыть снова: значок капли у часов (справа внизу, может прятаться под стрелкой ^) → «Подключение…».

3. Если Windows спросит про микрофон — разреши. Проверить: Параметры → Конфиденциальность → Микрофон →
   «Разрешить классическим приложениям доступ к микрофону» должно быть включено.

КАК РАБОТАЕТ
• Держи amoCRM открытой в Chrome. Звони в наушниках — так голоса не смешаются.
• Sipuni: открой сделку клиента и звони. После звонка итог сам ляжет в «Примечание» этой сделки.
• WhatsApp: Droplet возьмёт номер из окна звонка, найдёт клиента в amoCRM и сам откроет его сделку.
  После звонка итог — в её «Примечание».
• В примечании сначала КЛЮЧЕВОЕ (город, цель, для кого, прайс, личное, договорённости), потом ВЕСЬ ДИАЛОГ.
• Предупреждай клиента, что разговор записывается.
• Итог готов через несколько минут после звонка — ждать не нужно, работай дальше.
• Если Droplet не уверен, чья это карточка (переключил сделку во время звонка, у номера два контакта,
  номер не виден в окне звонка), — в amoCRM он НЕ пишет. Итог будет в буфере: открой нужную сделку и вставь Ctrl+V.
• Все записи и итоги: значок капли → «Папка звонков» (Документы → Droplet Звонки).
• Выключить автозапись: значок капли → «Записывать звонки сам».
• Ключей от amoCRM нет ни у кого: пишет расширение от имени того, кто вошёл в amoCRM.
